# Отчёт о качестве данных

Датасет: `synthetic_healthcare_data.csv`


## 1. Введение

Данные — 500 записей о госпитализациях пациентов. Есть возраст, пол, ИМТ, давление, холестерин, курение, диабет, диагноз, стоимость лечения, даты поступления и выписки, исход.

Заказчик — аналитический отдел клиники или страховая компания.

Задачи ИАД:
1. Описательная аналитика.
2. Поиск аномалий.
3. Сегментация пациентов.
4. Прогноз исхода лечения.

---

## 2. Паспорт датасета

- Размер: 500 строк × 13 столбцов.
- Пропусков нет.
- Дубликатов нет.
- `Patient_ID` уникален.
- После преобразований добавлены: `BP_Systolic`, `BP_Diastolic`, `Length_of_Stay`.

---

## 3. Проблемы качества данных

1. Опечатка в категории. В столбце `Outcome` есть значение `Deceases` вместо `Deceased`. Риск: ошибки в моделях классификации. Решение: заменить на `Deceased`.

2. Невозможные значения. Диастолическое АД часто больше или равно систолическому. Риск: ложные выводы о связи давления с исходом. Решение: пометить как `NaN` или скорректировать.

3. Неудобный формат. `Blood_Pressure` хранится строкой «Sys / Dia». Риск: нельзя напрямую считать статистики. Решение: разделить на два числовых признака.

4. Выбросы. `Treatment_Cost` сильно скошена вправо, есть выбросы по IQR. Риск: искажение средних и моделей. Решение: лог-трансформация или winsorization.

5. Ошибки в датах. Есть записи с `Length_of_Stay ≤ 0`. Риск: неверный анализ длительности госпитализации. Решение: проверить вручную и исключить.

6. Отсутствовал признак длительности. Не было `Length_of_Stay`. Риск: сложнее разведочный анализ. Решение: вычислить из дат (сделано).

## 4. План улучшения

1. Исправить опечатку в `Outcome`.
2. Обработать невозможные значения АД.
3. Исправить `Length_of_Stay ≤ 0`.
4. Разделить `Blood_Pressure` (сделано).
5. Привести даты к `datetime` (сделано).
6. Обработать выбросы `Treatment_Cost`.
7. Нормализовать числовые признаки (отложено).
8. One-hot encoding категорий (отложено).

## 5. Резюме

Данные чистые по пропускам и дубликатам, но есть опечатки, физиологически невозможные значения АД, выбросы в стоимости лечения и ошибки в датах. Всё это нужно исправить до моделирования. После очистки датасет подходит для аналитики, кластеризации и прогноза исхода.
