# Лабораторная работа №1
## Первичное исследование и оценка качества данных

Учебный проект по дисциплине «Введение в интеллектуальный анализ данных».
Выполняется на синтетическом датасете о госпитализациях пациентов.


## Структура проекта

- README.md
- .gitignore — исключения для git
- data/synthetic_healthcare_data.csv — датасет (500 × 13)
- notebooks/01_data_understanding.ipynb — анализ
- report/quality_report.md — текстовый отчёт


## О датасете

synthetic_healthcare_data.csv — синтетические данные о госпитализациях пациентов.

Размер: 500 строк × 13 исходных столбцов.

Признаки:
- демографические: Age, Gender;
- клинические: BMI, Blood_Pressure, Cholesterol_Level;
- факторы риска: Smoker, Diabetic;
- диагноз и исход: Diagnosis, Outcome;
- экономические и временные: Treatment_Cost, Admission_Date, Discharge_Date.


## Цели работы

1. Описать датасет в терминах задачи ИАД (заказчик, вопросы к данным).
2. Выполнить первичный обзор: размер, структура, типы, базовая статистика.
3. Провести аудит качества данных: пропуски, дубликаты, подозрительные значения, выбросы.
4. Построить осмысленные визуализации для разведочного анализа.
5. Оформить результаты в воспроизводимом виде.


## Требования и запуск

1. Убедитесь, что у вас установлен Python (версии 3.8+).
2. Установите необходимые библиотеки (pandas, numpy, matplotlib, seaborn)
